# Исторические материалы и исследования

Эти документы сохраняют происхождение наблюдений, исправлений и CI-проверок.
Они не являются текущими инструкциями, доказательством доступности backend
сегодня или сообщением о наличии действующей сессии. Реальные аккаунтные кэши
были удалены; архивные фразы о сохранении сессии описывают только прошлый запуск.
GitHub Release 1.7.0 опубликован; прежние freeze/policy hold в хронологии
относятся к моменту записи и не являются текущим запретом публикации.
